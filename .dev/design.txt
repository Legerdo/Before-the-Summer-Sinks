여름이 가라앉기 전에 (Before the Summer Sinks) — internal design notes
======================================================================

HOOK: 8월 31일이 지나면 물에 잠기는 충북 산골 마을 '소리실'. 폐교 방송실에서 불법 심야 라디오(88.3MHz)를
하는 소녀 하윤슬과, 댐 기술자 아버지를 따라 일곱 번째 전학을 온 소년 서한결의 40일.
THEME: 사라지는 것을 기억하는 법 / 작별(잘 가) vs 다녀와. 그는 듣는 법을, 그녀는 떠나는 법을 배운다.
Title double meaning: 엄마 이름이 '강여름'. 윤슬 = 햇빛에 반짝이는 물결 (마을이 물이 되어도 그 위엔 윤슬).

CHARACTERS
- 하윤슬 (17, 고2): 헤드폰(엄마 유품, 오렌지 레트로) 목에 걸고 녹음기 들고 다님. 날카로운 귀, 장난스럽고
  직설적, 방송 중엔 전혀 다른 매끄러운 DJ 톤. 약점: 작별 인사를 못 함("잘 가"를 한 번도 말한 적 없음),
  마이크 앞에서만 진심을 말함. 엄마의 마지막 테이프("윤슬이가 소리실을 떠나는 날")를 5년째 안 들음.
  아빠는 청주 이주아파트에 먼저 감(전화만). 봉순 할머니가 챙겨줌. 소리 지도 100개(#100은 비워둠).
  호칭: 한결→"철새". 말투: 반말, 짧고 빠름, 가끔 "~거든?".
- 서한결 (17, 주인공, 무음성): 7번째 이사. 노이즈캔슬링 이어폰(아무것도 안 틂). "정 붙이지 않기". 기계 손재주 약간.
- 서정훈 (47): 아버지, 소리실댐 공사 현장 책임 기술자. 피곤하지만 다정. 잠기는 마을마다 사진을 찍어 둠(17개 마을 앨범).
- 김봉순 할머니 (78): 봉순상회. 충청 사투리(가볍게: ~여, ~유, 그려). 남편 박만복(전 이장, 2년 전 작고)의 마을방송 테이프.
- 강여름 (윤슬 엄마, 5년 전 병으로 작고, 당시 39): 분교 음악교사, 원조 '소리실 심야방송' DJ. 테이프 속 목소리만.
- 박만복 (故 이장): 테이프 속 마을방송 목소리. "…봉순아, 칼국수 남겨 놔."
- 통화 사연 주민들(전화 필터), 공단 직원(설명회).

STRUCTURE (target ~80-95 min)
P  프롤로그: 폭풍 속 라디오 목소리(콜드오픈) → 타이틀 → 7월 22일.
1  철새: 버스정류장/수몰 현수막, 봉순상회, 임시 숙소, 첫날 밤 88.3 수신, 개울에서 첫 만남("쉿!"), 봉순의 사연 편지 → 밤의 폐교 방송실, 방송 사고(한결 목소리 송출) → "너 내일부터 내 조수야." [C1 수락/거절(대사 차이, aff)]
2  소리 수집가: 새벽 기상, 소리 지도 100개, 정자나무 매미/개울/논, 이어폰 벗기, 메아리 바위 석양 [C2 외칠 말: 야호/거기 누구 없어요/하윤슬 바보 → echo flag, 엔딩 회수], 공동진행 첫 방송, 별길 귀가.
3  늘어진 테이프: 봉순의 테이프, 수리(CG), 이장 목소리 + 엄마 목소리 등장 → 윤슬 뛰쳐나감, 엄마/마지막 테이프 고백, 방송에서 이장 목소리 송출(봉순 CG), 봉순 이사 날 윤슬이 숨음 [C3 데려간다(brave)/대신 인사] → "잘 가 대신 다녀와" 모티프.
4  88.3MHz: 라디오 나눠주기(태풍 복선), 반딧불 개울(CG) 엄마 이름 여름 [C4 아빠 일 고백 honest / 침묵], 청취자 코너, 주민설명회: 아버지 등장, 불법방송 신고 → 방송 중단. "그날 밤 88.3에선 아무 소리도 나지 않았다."
5  무음: 철거 소리, 부자 대화(사진 앨범), 메아리 바위 화해 [C5 계속 듣고 싶어 / 미안해 / 골짜기에 외치기] → 마지막 방송 계획, 주민 메시지 수집, 태풍 예보.
6  태풍의 밤: 정전·통신두절, 아랫말 침수 위험, 배터리 송출 긴급방송(CG), 안테나 복구, "철새, 들려? 대답 안 해도 돼. 그냥 들어." 전원 무사, 새벽(CG 어깨).
7  마지막 방송: 고향 기억식(봉순 재회), 소리 지도 몽타주, 주민 목소리, 엄마 테이프(CG) "잘 가 대신, 다녀와", "잘 있어, 소리실… 아니, 다녀올게." 마이크 없는 고백. [C6 #100에 남길 말: 다녀와 / 잘 가 / 좋아해]
E  TRUE "윤슬"(aff>=4 & C6!=잘가): 4년 후 호수, 메아리 없음 → 뒤에서 대답(C2 회수), 어서 와. / NORMAL "잔향": 4년 후 도시의 밤, 라디오 속 그녀 목소리.

ART DIRECTION: 고품질 2D 일본 애니 스타일, 깔끔한 선, 부드러운 셀 셰이딩, 여름빛(청록/하늘색/녹음 + 오렌지 포인트),
배경은 회화적이고 빛이 강한 한국 시골(돌담, 슬레이트/기와 지붕, 정자나무, 논, 개울, 산 능선), 텍스트 없는 간판.
UI 모티프: 라디오 주파수 다이얼, 카세트 라벨, 종이 테이프, 물결(윤슬) 하이라이트.

TECH: Vite+TS DOM 스테이지(1920x1080 논리 해상도 스케일), Web Audio(버스: bgm/amb/se/voice/sys, voice FX radio/tape/pa/phone/echo),
사전 분석 립싱크 envelope, .vn 스크립트 → JSON 컴파일(안정 line id, voice id 명시), Electron 래퍼(app:// 프로토콜).
Voice: Fish s2.1-pro-free zero-shot clone. 윤슬 ref = art_work/voice_seed/ys_02.wav (F0~261Hz, expressive). 무료 API credit=0 → voice design 불가.
Codex image_gen: desktop codex.exe (0.159.2) works with default model; npm 0.158 needs -m gpt-5.5. 1024x1536 portrait, transparent OK.
Edits keep near pixel alignment (ECC warp ~identity) → face/eye/mouth patch compositing pipeline.
